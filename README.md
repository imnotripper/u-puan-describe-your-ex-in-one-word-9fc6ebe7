# Describe Your Ex in One Word

Your ex, summed up in exactly one word.

> Placeholder

## How to run

```sh
python3 main.py
```

This writes the word to `/output/entry.txt` (creating `/output` if needed). The file contains exactly the word: one word, UTF-8, 11 characters — inside the 1–111 character gate, with no trailing newline and nothing attached.

## How it was chosen

Ten candidate words were written and duelled pairwise against the judge brief (instantly readable as a verdict on an ex, comic punch, surprise, craft, recognition). See [CANDIDATES.md](CANDIDATES.md) for the full list and the winner's rationale.
